# Week 1 : Finalizing Requirements & GitHub Strategy

# Project Strategy

## Goal:
Finalize the project requirements, define user roles, and establish the GitHub repository strategy for a team of 3.

## Relevant Context
We need to ensure Keshav (Frontend) and Vijay (Backend) can work smoothly without merge conflicts. We also need a clear definition of what ServeConnect is.

## Key Observation
Without a clear MVP definition, feature creep (like complex bookings and payments) might derail the timeline. A solid branching strategy is required.

## Solution
- Defined core MVP: Worker Registration -> Admin Approval -> Customer Search -> Call Now.
- Established User Roles: Customer, Worker, Admin.
- Established branch strategy: `main` (production), `backend` (Vijay's work), and `frontend` (Keshav's work).
